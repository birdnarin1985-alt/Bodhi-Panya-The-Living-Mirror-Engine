การวิเคราะห์พฤติกรรมกำลังอัดคอนกรีตระดับจุลภาค (Micro-Mechanics)

บันทึกวิศวกรสนาม: จำลองโครงสร้างมวลรวม (Aggregates) และแรงยึดเกาะซีเมนต์เพสต์

ในงานก่อสร้างหน้างานจริง กำลังอัดของคอนกรีต ($f'_c$) ไม่ได้ขึ้นอยู่กับปูนซีเมนต์เพียงอย่างเดียว แต่ถูกขับเคลื่อนด้วยระบบเครือข่ายความสัมพันธ์ระหว่างมวลรวมหิน ทราย และสารยึดเกาะ โมเดลนี้จำลองโครงสร้างอนุภาคผ่านคณิตศาสตร์เชิงกลศาสตร์วัสดุ

Mohr-Coulomb Failure Criterion:
$\tau = c + \sigma_n \tan(\phi)$

โดยที่:
• $\tau$ = กำลังต้านทานแรงเฉือน
• $c$ = แรงยึดเหนี่ยวซีเมนต์เพสต์ (Cohesion)
• $\sigma_n$ = ความเค้นตั้งฉากบนระนาบวิบัติ
• $\phi$ = มุมเสียดทานภายใน (Internal Friction)

เมื่อแรงกดอัดจากภายนอกเพิ่มสูงขึ้น แรงเค้นจะถ่ายเทผ่านเครือข่าย Linked List หากเกินขีดจำกัดความเค้นสูงสุด ($100\%$) พันธะซีเมนต์จะเกิดรอยร้าวต่อเนื่อง (Micro-cracking) นำไปสู่การวิบัติของโครงสร้างในที่สุด
